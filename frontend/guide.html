ບົດທີ 1

ຫຼັກການວັດແທກໄລຍະຫ່າງດ້ວຍກ້ອງດຽວ (Triangle Similarity)

ວິທີປ່ຽນຂະໜາດ Pixel ໃນພາບ ໃຫ້ກາຍເປັນໄລຍະຫ່າງຕົວຈິງ (ແມັດ)

ເມື່ອລົດຄັນໜ້າຢູ່ໄກ ກ່ອງສີ່เหลี่ยม (Bounding Box) ທີ່ AI ກວດຈັບໄດ້ຈະມີຂະໜາດນ້ອຍ. ແຕ່ເມື່ອລົດຫຍັບເຂົ້າໃກ້ ກ່ອງຈະໃຫຍ່ຂຶ້ນ. ເຮົາໃຊ້ສູດຄະນິດສາດດັ່ງນີ້: 

Distance (D) = (Known Width (W) × Focal Length (F)) / Pixel Width (P)
  • W (Known Width): ຄວາມກວ້າງຕົວຈິງຂອງລົດເກັງໂດຍສະເລ່ຍ (~1.8 ແມັດ)
  • F (Focal Length): ຄ່າຄວາມຍາວໂຟກັສຂອງກ້ອງ (ເຊັ່ນ: 800)
  • P (Pixel Width): ຄວາມກວ້າງຂອງກ່ອງລົດທີ່ວັດແທກໄດ້ໃນພາບ (`x2 - x1`)

🧪 ຫ້ອງທົດລອງຄິດໄລ່ໄລຍະຫ່າງ (Formula Simulator)

ລອງລາກປັບຄ່າ Pixel ຫຼື Focal Length ເພື່ອເບິ່ງວ່າໄລຍະ 30 ແມັດຄິດໄລ່ອອກມາແນວໃດ

ຄວາມກວ້າງຕົວຈິງຂອງລົດ (W): 1.8 ແມັດ
ຄ່າ Focal Length ຂອງກ້ອງ (F): 800
ຄວາມກວ້າງຂອງລົດໃນພາບ (P): 48 Pixels
ຜົນລັບໄລຍະຫ່າງ (D = W × F / P):
30.0 ແມັດ
ພໍດີເກນ 30m
ບົດທີ 3

ໂຄ້ດ Python ກວດຈັບລົດດ້ວຍ YOLOv8

ການດຶງຄ່າ Bounding Box ມາຄິດໄລ່ໄລຍະ 30 ແມັດ

# ດຶງພິກັດກ່ອງສີ່เหลี่ยมຈາກ YOLOv8
x1, y1, x2, y2 = map(int, box.xyxy[0])
pixel_width = x2 - x1

# ຄິດໄລ່ໄລຍະຫ່າງ
distance = (KNOWN_WIDTH * FOCAL_LENGTH) / pixel_width

if distance < 30.0:
    print(f"WARNING! ລົດຢູ່ໃກ້ເກີນໄປ: {distance:.1f}m")
