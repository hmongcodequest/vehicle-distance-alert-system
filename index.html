🛠️ ບັນທຶກການແກ້ໄຂບັນຫາຕົວຈິງໃນໂປຣເຈັກ (Real-World Troubleshooting Notes)

ສະຫຼຸບ 4 ບັນຫາສຳຄັນທີ່ເຮົາພົບຕອນທົດສອບກັບວິດີໂອແທ້ `dome.mp4` ແລະ ວິທີແກ້ໄຂໃນລະຫັດ

1. ບັນຫາຕິດຕັ້ງ `pygame` ໃນ Python 3.14 (`No module named distutils`)

ສາເຫດ: Python 3.14 ຕັດໂມດູນ distutils ອອກ ເຮັດໃຫ້ pygame 2.6.1 ບໍ່ສາມາດ Build Wheel ເທິງ Windows ໄດ້.
ວິທີແກ້: ປ່ຽນໄປໃຊ້ pygame-ce ໃນ requirements.txt ຫຼື ໃຊ້ໂມດູນມາດຕະຖານ winsound + wave ໃນ audio_manager.py ເຊິ່ງເຮັດວຽກໄດ້ທັນທີໂດຍບໍ່ຕ້ອງຕິດຕັ້ງ Library ເພີ່ມ.

2. ການແຍກໄຟລ໌ຕັ້ງຄ່າເຂດເລນ (`lane_config.json`) & ເຊື່ອງເສັ້ນ `lane_top_y`

ວິທີແກ້: ສ້າງໄຟລ໌ select_lane_roi.py ເພື່ອຄລິກກຳນົດ lane_points (4 ຈຸດ) ແລະ lane_top_y ແລ້ວບັນທຶກເປັນ JSON ກ່ອນ. ຈາກນັ້ນໃນ full_system_30m.py ໃຫ້ໃຊ້ lane_top_y ກວດສອບຢູ່ເບື້ອງຫຼັງໂດຍເຊື່ອງ (Hide) ບໍ່ແຕ້ມເສັ້ນ Line Y ອອກມາບັງໜ້າຈໍ.

3. ລົດຢູ່ໄກກວດຈັບບໍ່ເຫັນ & ກ່ອງຍັກກວດຈັບເສົາລົດຕົວເອງ (`Out: 1.2m`)

ວິທີແກ້: ຕັດພາບ (Crop) ສະເພາະບໍລິເວນປ່ອງຢ້ຽມໜ້າລົດອ້ອມຮອບເຂດເລນສີຟ້າກ່ອນສົ່ງໃຫ້ YOLOv8 (imgsz=960) ເພື່ອຊູມຫາລົດໄລຍະໄກ ແລະ ໃຊ້ utils/geometry_filter.py ຕັດກ່ອງທີ່ກວ້າງເກີນ 22% ຂອງຈໍຖິ້ມ.

4. ກ່ອງສີແດງ `WARNING!` ຊ້ອນທັບກັນຫຼາຍອັນເທິງລົດຄັນດຽວ

ວິທີແກ້: ເປີດໃຊ້ agnostic_nms=True ໃນ YOLOv8 ຮ່ວມກັບຟັງຊັນ remove_overlapping_boxes() ໃນ utils/bbox_nms.py ເພື່ອກວດຄ່າ Containment Ratio ແລະ ຍຸບກ່ອງຊ້ອນກັນໃຫ້ເຫຼືອພຽງ 1 ກ່ອງຕໍ່ລົດ 1 ຄັນ.
